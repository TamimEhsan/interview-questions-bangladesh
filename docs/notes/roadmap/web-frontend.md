# Web & Frontend

*Part of the [Interview Prep Roadmap](./). Coverage ratings are explained there.*

*Optional track — relevant if the role touches frontend work.*

## Frontend Fundamentals
JavaScript and DOM basics, CSS, then framework-specific questions (commonly React).

*Coverage: moderate*

### JavaScript Fundamentals
- Types, coercion, and equality
- Scope, closures, and hoisting
- `this` binding
- Prototypes and classes
- Callbacks, promises, and async/await
- The event loop

### DOM & Browser
- DOM tree and element selection
- Event handling, bubbling, and delegation
- Browser rendering pipeline
- Cookies, `localStorage`, and `sessionStorage`

### HTML & CSS
- Semantic HTML
- Box model
- Flexbox and grid
- Responsive design and media queries
- Specificity and the cascade

### Frameworks
- Component-based architecture
- State management
- Lifecycle and hooks
- Virtual DOM and reconciliation

### Frontend Performance
- Bundle size and code splitting
- Lazy loading
- Caching and asset optimization
